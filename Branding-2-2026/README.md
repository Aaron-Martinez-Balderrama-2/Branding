# Branding — Proyecto #80: SIGAV-UAGRM

**Software de Monitoreo y Control de Acceso Vehicular mediante el Modelo YOLOv8 y OCR para la Universidad Autónoma Gabriel René Moreno (UAGRM).**

- **Facultad:** Facultad de Ingeniería en Ciencias de la Computación y Telecomunicaciones (FICCT)
- **Carrera:** Ingeniería en Sistemas
- **Materia:** Taller de Grado INF511 SS
- **Grupo / Proyecto:** #80

## Estructura del Repositorio

- `Banners/`: 2 propuestas en formato PDF a tamaño real (**60 cm × 120 cm**).
- `Credenciales/`: 2 propuestas verticales listas para imprimir (**4 expositores**).
- `Logos/`: Logos oficiales (UAGRM, IICCT Investigación, FICCT), logos vectorizados/limpios de SIGAV-UAGRM y código QR oficial.
- `Tripticos/`: 2 propuestas de tríptico horizontal tiro y retiro (**6 caras**).
